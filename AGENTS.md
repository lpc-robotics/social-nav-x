# Repository contribution rules

- Every commit pushed to this repository must use
  `lpc-robotics <lpc-robotics@users.noreply.github.com>` as both its author and
  committer identity.
- Never use an automated agent, assistant, tool, bot, or local placeholder
  identity as a commit author or committer.
- Before pushing rewritten or imported history, audit both author and committer
  fields for every commit reachable from the target branch.
